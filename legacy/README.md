Use Python 3.11 or later. Open PowerShell in `legacy/`.

1. Install dependencies:

   ```powershell
   python -m pip install -r requirements.txt
   ```

2. Open `config.json`, put your API key in `openai_api_key`, and retain the model `gpt-5.6-sol`. If the file does not exist, such as after cloning, create it next to `app.py` with:

   ```json
   {
     "openai_api_key": "",
     "model": "gpt-6.1-sol"
   }
   ```

   Git ignores this file to keep real keys out of commits. The application reads the key from this file rather than an environment variable. API requests may incur charges.

3. Run:

   ```powershell
   python -m streamlit run app.py --server.address 127.0.0.1 --browser.gatherUsageStats false
   ```

4. Open the [local interface](http://127.0.0.1:8501), enter a prompt, and click **Send**. The default is **Central Hub - Local Runtime**: Hub → Root Router → selected package set → response. Send only when you intend to call the live API. M1 was verified with static checks and mocks, which do not start a live campaign.

History is kept in the Streamlit session and is never written to `sessions/`. Reloading the page or restarting the app may lose history. Failed turns are not added to history. The prompt remains available to send again. The interface reports missing keys, exhausted quota, connectivity problems, and unavailable model access as errors. These do not establish a live PASS.
